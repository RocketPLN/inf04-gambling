# AGENTS.md

INF.04 Portal. Polish study app for the INF.04 technik programista practical exam. It lists CKE exam sheets (2021-2026, styczen/czerwiec sessions) as cards on the home page. The exam detail page (`/egzamin/$examId`) shows the sheet PDF in the browser's native viewer plus the task list and attachments.

## Stack

React 19, Vite 8, TanStack Start (SSR, Nitro server) with TanStack Router file-based routes, TypeScript in strict mode (`npm run typecheck`, chained into `npm run build`), oxlint for lint. The exam PDF renders in the browser's native viewer (`<iframe>`, never `react-pdf` — it ships its own React copy and crashes with invalid hook call). There is no test runner. Direct URLs (e.g. `/egzamin/<id>`) are server-rendered by Node — no SPA 404.

Environment I saw: Node v24, npm 11.

## Commands

All from repo root. The repo has both `package-lock.json` and `pnpm-lock.yaml`, but scripts and docs assume npm, so use npm.

- `npm run dev` starts Vite locally (`vite dev`, SSR on :3000).
- `npm run build` builds the Nitro server to `.output/`.
- `npm run start` runs the production server (`node .output/server/index.mjs`).
- `npm run preview` serves the production build.
- `npm run lint` runs `oxlint`.
- `npm run download` runs `scripts/download-pdfs.js`, fetches PDFs and ZIPs from arkusze.pl plus extra CKE task versions (zad 02/03) into local `public/pdfs/` (dev cache, gitignored).
- `npm run setup` chains download and build. It hits the network and takes a while, so prefer `dev` for normal work.

## Layout

- `src/router.jsx` exports `getRouter()` — the Start router entry (replaces the deleted SPA `src/main.jsx`).
- `src/routes/__root.jsx` shared shell (ticker, jackpot bar, header, footer, bonus bar) plus the `<html lang="pl">` document (`shellComponent` with `HeadContent`/`Scripts`, `head()` with title/meta/fonts — replaces the deleted `index.html`).
- `src/routes/index.jsx` home page, exam grid, filters, search params `q`, `year`, `session`.
- `src/routes/egzamin.$examId.jsx` exam detail page: loader finds the exam by `params.examId`, throws `notFound()` for unknown ids.
- `src/components/app/plan-detail.jsx` exam detail layout: header, R-anchor buttons, `PdfViewer`, task list, files.
- `src/components/app/pdf-viewer.jsx` PDF preview, native `<iframe>` viewer (see PDF preview section).
- `src/routeTree.gen.ts` generated by the TanStack Start Vite plugin. Never edit by hand.
- `src/data/exams.js` source of truth for exams, plans, and scoring. 20 entries: `inf04-2021-czerwiec` through `inf04-2026-czerwiec`, plus zad 02/03 variants (`<id>-z2`, `<id>-z3`) for sessions that had multiple task versions.
- `src/components/CasinoScam.ts` jackpot bar, slot machine, fake winners ticker, bonus bars. All satire, all intentional.
- `src/App.css`, `src/index.css` global styles, brutalist and casino classes live here.
- `scripts/download-pdfs.js` downloader for PDFs and ZIPs.
- `public/pdfs/` local dev cache (gitignored, only `.gitkeep` tracked). Canonical file store is the Cloudflare R2 bucket `inf04` (free tier, zero egress), filenames 1:1 with the old convention (`<id>-arkusz.pdf`, `<id>-zasady.pdf`, `<id>-zalaczniki.zip`, plus `<id>-z2-…` / `-z3-…` variants). `exams.js` points at R2 absolute URLs; the viewer still tries same-origin `/pdfs/…` first (HEAD) so local files win in dev. CKE publishes some zasady as XLSX — those are converted to PDF by `scripts/xlsx_to_pdf.py` (needs `pip install openpyxl fpdf2`), only PDFs stay in the repo. CKE attachment ZIPs/7z are password-encrypted (exam-day password); only decrypted repacks from arkusze.pl open directly.
- `.oxlintrc.json` enables `react` and `oxc` plugins. `react/rules-of-hooks` is an error, `react/only-export-components` is a warn with `allowConstantExport`.

## Routing

Routes are file-based. Adding `src/routes/foo.jsx` with `createFileRoute("/foo")` is enough, the Vite plugin regenerates `routeTree.gen.ts` on `dev` and `build`.

Search params are the filter state. `__root.jsx` validates them (`q` string, `year` string or `"all"`, `session` `"styczeń"`, `"czerwiec"`, or `"all"`). `index.jsx` reads them with `Route.useSearch()` and writes with `navigate({ search })`. Keep these three files in sync when you touch filters. Session strings contain Polish diacritics, match them exactly.

## Data model

Each object in `src/data/exams.js` looks like this:

`id`, `year` (number), `session` (`"styczeń"` or `"czerwiec"`), `title`, `subtitle`, `pdfArkusz`, `pdfZasady`, `zipZalaczniki` (path or `null`), optional `zipRemote`, `tech` (array), `czas` (minutes), `plan` (`opis`, `zadania`, `pliki`, `wymagania`), `scoring` (array of R1-R4 groups, each with `grupa`, `max`, and `kryteria` of `kod`, `opis`, `pkt`).

Every criterion is worth 1 pkt. Group `max` equals its criteria count and exam total is the sum of group maxes. Derive totals with `reduce`, never hardcode them in new UI.

The same exam list is duplicated in `scripts/download-pdfs.js`. There is no shared import. When you add or rename an exam, update both files plus the local PDFs in `public/pdfs/` or downloads and UI will drift apart.

## PDF preview

`PdfViewer` (`src/components/app/pdf-viewer.jsx`) shows the arkusz PDF in the browser's native viewer (`<iframe>`). It HEAD-checks same-origin `/pdfs/<id>-arkusz.pdf` first and falls back to the remote R2 URL on error (in production `public/pdfs/` is gitignored, so R2 always serves). No zasady preview — only the arkusz is shown. Never reintroduce `react-pdf` — it ships its own React copy and crashes the exam page with invalid hook call.

`download-pdfs.js` still fetches sources into `public/pdfs/`, and `scripts/xlsx_to_pdf.py` still converts CKE XLSX zasady to PDF. Do not commit fresh multi-megabyte PDFs unless asked, they bloat the repo. There is no HTML conversion anymore — `public/plans/`, `transform_pdfs.py`, and `pdf_to_html.py` were removed; do not reintroduce them.

## Style is intentionally ugly

The casino look is the point. Marquee tags, Comic Sans inline styles, jackpot counters, fake winner tickers, RTP pills, kurs multipliers, "ODBIERZ BONUS" buttons, testimonial jokes, guest counters, `FungusWhisper` mushroom traces. Do not "fix" these, do not normalize them into clean corporate UI, do not remove jokes in a refactor. Keep Polish copy as is, including diacritics and caps-lock shouting.

`FungusWhisper` renders a subtle mushroom marker, `variant="corner"` for card corners. It appears on every 5th card and in a few footers. Leave it.

## State and conventions

Write TSX in the existing style: function components, hooks at top, double quotes, Polish UI strings. Type every prop interface and data shape — `tsc --noEmit` must stay clean.

## Verification

There are no unit tests, so verification is lint plus build plus a manual pass.

1. `npm run lint` must be clean.
2. `npm run build` must pass (vite + `tsc --noEmit`), which also regenerates the route tree.
3. `npm run dev`, open `/`, filter by a tech tag and a session, open an exam, check the PDF preview loads, check back navigation restores filters.
